# com.airtribe.learntrack.util

This package contains utility helpers used by LearnTrack.

## Contents

- `InputUtil.java` — helper methods for reading console input and printing output.
- `InputValidation.java` — validation utilities for email addresses, non-empty strings, and integer parsing.
- `IdGenerator.java` — sequential ID generator for students, courses, and enrollments.

## Purpose

Use this package for reusable support functions that simplify UI input handling and shared utility behavior.
