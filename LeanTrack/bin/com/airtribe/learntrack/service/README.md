# com.airtribe.learntrack.service

This package contains the service layer for LearnTrack.

## Contents

- `StudentService.java` — manages student creation, lookup, update, deactivation, and removal.
- `CourseService.java` — manages course creation, lookup, listing, and deactivation.
- `EnrollmentService.java` — manages enrollments between students and courses.

## Purpose

Use this package to implement business logic and coordinate operations across entity objects. It acts as the middle layer between the UI and domain entities.
